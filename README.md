# Sales-Report
# December Sales Analysis Dashboard
# Project Overview

This project analyzes December sales performance across multiple e-commerce channels including Ajio, Amazon, Flipkart, Meesho, Myntra, Nalli, and Others. The dataset contains sales distribution by customer age group and product size.

# Key Metrics
Total Sales Volume: 1,622,033 units
Channels Analyzed: 7
Customer Segments: Adults, Middle, Senior
Product Sizes: XS, S, M, L, XL, XXL, 3XL, 4XL, 5XL, 6XL, Free Size

# Key Findings
Amazon contributed over 31% of total sales.
Myntra and Flipkart together represented nearly 49% of total sales volume.
Core sizes (M, L, XL) accounted for the majority of demand.
Adult consumers were the primary sales drivers across all marketplaces.
